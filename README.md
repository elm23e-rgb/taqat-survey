# استبيان منظومة طاقات

صفحة ثابتة (`index.html`) تُنشر على GitHub Pages. تُحفظ الإجابات في جدول Google Sheets عبر `apps-script/Code.gs`.

## تفعيل استلام الإجابات (مرة واحدة)

1. أنشئ جدول Google جديدًا باسم «إجابات استبيان طاقات».
2. من القائمة: **الإضافات ← Apps Script**. احذف الكود الموجود والصق محتوى `apps-script/Code.gs`، ثم احفظ.
3. اضغط **نشر ← نشر جديد**، واختر النوع **تطبيق ويب**، وضع: التنفيذ باسمي، والوصول **أي شخص**. اضغط نشر ووافق على الصلاحيات.
4. انسخ **رابط تطبيق الويب** (ينتهي بـ `/exec`).
5. افتح `taqat/index.html` وضعه بين علامتي الاقتباس في السطر `var ENDPOINT = '';` ثم احفظ وارفع التعديل.

بعد النشر يمتلئ الجدول بصف لكل إجابة. وإن عدّلتَ `Code.gs` لاحقًا فانشر نسخة جديدة من التطبيق.

## تعديل النصوص

كل النصوص في الكائن `CONTENT` داخل `taqat/index.html`. والصفحة الرئيسية `index.html` تحوّل إليها.

## الخطوط

خطوط ثمانية في مجلد `fonts/`. تأكد من ترخيصها قبل النشر العام.
